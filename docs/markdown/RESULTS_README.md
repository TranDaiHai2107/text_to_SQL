# Kết quả

`application/evaluate_results.json` là kết quả đánh giá nội bộ của ứng dụng PostgreSQL/tiếng Việt, không phải điểm CLINSQL. Chưa có prediction, SQL Score hoặc Execution Score từ protocol CLINSQL. Khi chạy validation/test, lưu prediction và usage theo protocol hash, tách inference cost khỏi evaluation cost.
