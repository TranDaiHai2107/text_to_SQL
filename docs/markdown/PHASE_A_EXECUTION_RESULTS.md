Tiếp theo, dùng `metadata.schema_records_from_manifest` làm input cho `agentic.schema.Schema` và xây Schema RAG index với manifest hash được khóa. Giữ `clinsql.runner.run_validation_one` mock-only làm regression boundary; tạo đường runner thật riêng, tiêm chung `BigQueryAdapter` vào CLINSQL CoT, MAC-SQL, SDE-SQL và Ours, không sửa source dưới `external/` hoặc prompt/agent/probe/candidate logic. `BigQueryClient` hiện chỉ nhận approval `phase_a_smoke`, nên Phase B cần approval/policy riêng trước mọi SQL validation trên MIMIC. Không dùng lại hồ sơ Phase A cho benchmark.

Trước pilot, hoàn thiện `BenchmarkExecutionConfig` với row cap đã khảo sát trên validation, durable budget/checkpoint, scalar/multi-row result serialization, retry status taxonomy và kiểm tra `Execution.complete`; mọi output bị truncate phải được đánh dấu riêng và không đưa vào official scoring. So sánh mock output/call order với snapshot hiện tại, rồi mới xác minh fidelity MAC-SQL/SDE-SQL. Dữ liệu probe nào được phép gửi LLM cần quyết định riêng.
