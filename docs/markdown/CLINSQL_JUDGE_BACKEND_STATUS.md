# CLINSQL judge backend status

- `CLINSQL_NATIVE_AZURE_JUDGE` · `NATIVE_JUDGE_UNAVAILABLE` trong phiên này. Endpoint và deployment chưa được xác minh. Chế độ native khóa deployment `gpt-5-chat`, Azure API `2024-12-01-preview`, Chat Completions một user message, `temperature=0.2`, 1024 completion tokens và lựa chọn token parameter từ hai tên có trong source. Tên parameter được khóa trước khi chấm. Preflight tổng hợp sẽ phát hiện trường hợp deployment không hỗ trợ các tham số này.
- `CLINSQL_ADAPTED_JUDGE` · `NOT_CONFIGURED`. Cần snapshot được chọn tường minh, model lookup và synthetic Chat Completions preflight trước khi truyền rows. Nếu snapshot hỗ trợ `temperature=0.2`, cấu hình có thể giữ giá trị đó. Nếu không hỗ trợ, để trống có chủ đích và lưu khác biệt trong config. `store=false` dùng cho OpenAI API. [OpenAI Chat Completions API](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create)
- Backend adapted xuất `ADAPTED_CLINSQL_SQL_SCORE` và `ADAPTED_CLINSQL_EXECUTION_SCORE`. Ledger lưu hash source/sample/prompt/config, model request/response, tham số, token usage, latency, trạng thái, grade, explanation và chi phí ước tính theo bảng giá đã nhập. Synthetic preflight usage được ghi riêng. Số lượt preflight tách khỏi `max_leaf_requests`; mỗi lần mở runner có một synthetic completion ngoài trần lượt leaf.

`python run.py clinsql-rubric pilot-manifest` tạo manifest từ audit và năm prediction đã khóa, chỉ in case IDs, paths và hashes. `config-hash --config <config.json>` tính fingerprint offline. Sau khi có thông tin triển khai hợp lệ, `run --config <config.json> --manifest <manifest.json> --approval <approval.json>` kiểm tra approval và thực hiện preflight trước khi chấm.

Config fields gồm `mode`, `model`, `endpoint`, `response_model`, `input_usd_per_million`, `output_usd_per_million`, `pricing_reference` và các trường tùy chọn `azure_token_parameter`, `temperature`, `cached_input_usd_per_million`. Approval cần `approved_by`, `policy_reference`, `expires_at_utc`, `send_complete_result_rows`, `manifest_sha256`, `judge_config_sha256`, `source_sha256`, `max_leaf_requests`. Đặt credential cục bộ và chỉ bật `SEND_RESULTS_TO_LLM` trong phiên chạy đã được duyệt. Dữ liệu gửi gồm câu hỏi, predicted SQL, tất cả result rows và yêu cầu lá rubric, cả cho SQL rubric lẫn Results rubric.
